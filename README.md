# 🪙 Atrapa Monedas

Juego hecho en Python con pygame-ce, mientras aprendo a programar.

## Cómo se juega
- **Flechas**: mover la bolita
- **Shift izquierdo**: correr (gasta stamina)
- **R**: reiniciar cuando se acaba el tiempo

Atrapa todas las monedas que puedas en 30 segundos. Cada moneda te devuelve un poco de stamina.
La bolita y la barra cambian de color según tu stamina: 🟢 → 🟡 → 🔴

## Cómo ejecutarlo
```
py -m pip install pygame-ce
py juego.py
```
